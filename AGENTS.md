# Stitches & Stories frontend

- Работать в `develop`. Не заменять историю пользовательских веток и не отправлять изменения в исходный шаблон.
- Companion API: https://github.com/aleksr777/stitches-stories-backend/tree/develop.
- Сохранять дизайн Stitches & Stories, русскоязычный интерфейс и адаптацию 320–3840 px.
- Использовать только настоящие фотографии изделий; при отсутствии оставлять явно обозначенные места для фото.
- Регистрация, вход и восстановление пароля — модальные окна; после авторизации в хедере круглая аватарка профиля.
- Не хранить JWT, пароли или контакты покупателя в browser storage. Корзина хранит только идентификаторы и количества.
- Согласия не отмечать заранее; не объединять документы; рекламная подписка необязательна. Версии и хеши документов получать из API.
- Новые сценарии тестировать через настоящий App (`test/store-flows.test.jsx`). Унаследованные сценарии отдельно используют `test/template-app.jsx`.
- Перед push: typecheck, lint, stylelint, prettier, npm test, build. Производственный build требует VITE_API_URL.
